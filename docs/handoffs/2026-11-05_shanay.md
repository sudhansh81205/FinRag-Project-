statement membership, grids, row/column positions, raw values, inline contexts,

## Rejections and storage rules

Shape-valid corruptions of period, scale, unit, metric, scope, raw/normalized
amount, footnotes, parent and coordinates fail deterministic source predicates.
Empty/duplicate/corrupt packages and swapped metadata rows fail. Missing data
or DVC leaves a saved blocked report. The reject-case ledger comes from executed
regressions, not financial benchmark outputs.

`prepare_evidence.py` allows byte-identical reruns and rejects any different
existing destination. New versions/filings use fresh directories. Other filing
directories and legacy MiniLM/Chroma artifacts are not replaced. This verifies
input storage safety; actual FAISS stale-row replacement/reload remains later work.

The real DVC check copies the actual four-file package, three sidecars and four
reference files, caches all 11 files, removes only those fresh copies, restores
them and repeats source/sidecar checks from the restored references. Before/after
file hashes, IDs and counts match. MLflow reopens the completed audit run and
downloads its saved JSON artifact for a byte comparison.
