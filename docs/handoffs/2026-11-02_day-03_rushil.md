## Failure distinctions

| Status | Meaning |
| --- | --- |
| `ok` | A real configured provider returned text from nonempty supplied evidence |
| `invalid_request` | Empty/invalid question or invalid retrieval limits |
| `index_not_ready` | No connected index, or canonical UI integration still incomplete |
| `insufficient_evidence` | Retrieval completed but no usable evidence remained; generation skipped |
| `service_error` | Retrieval/ranking/provider failed, or mock output was rejected |

`ok` today verifies provider transport and supplied-context plumbing. Citation
resolution, source sufficiency, unit-checked arithmetic and final answer quality
still need the later scheduled work and evaluation. Do not equate these smoke
checks with final financial correctness.
