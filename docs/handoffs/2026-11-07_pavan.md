### F14 fix (`scripts/verify_canonical_data.py`)

Repaired the directory creation ordering in `main()`.

**Before:** `artifacts.mkdir(parents=True, exist_ok=False)` executed before the `guarded()` call.
A `FileExistsError` or `PermissionError` would propagate uncaught and prevent any report from
being written — hiding its own failure evidence.

**After:** `artifacts.mkdir` moved inside `_guarded_build()` which is wrapped by `guarded()`.
An additional `args.output.parent.mkdir(parents=True, exist_ok=True)` ensures the output file
can always be written even when the artifacts directory fails.

Success: normal runs produce a saved report at the declared output path.
Failure: a `FileExistsError` on the artifacts dir is captured in the guarded report and exits
nonzero while still writing the diagnostic JSON.

## Viva explanation

1. **Why BM25 alongside dense?** Dense search finds semantically similar text; BM25 finds
   exact term matches. A query like "AAPL total net sales September 2021" may surface the
   exact cell via BM25 even when the dense embedding ranks a paraphrase higher.

2. **Why RRF instead of score combination?** Dense cosine scores and BM25 scores have
   incompatible scales. RRF uses only rank positions (1/(k+rank)), making fusion
   scale-agnostic and stable. k=60 is the established default; it dampens early-rank
   dominance.

3. **Why filter before top-k in BM25?** The same reason as dense: post-filtering a global
   top-k can miss the best eligible item if there are more than k ineligible items above it.
   An unindexed company returns an empty list, not a wrong answer.

4. **Why inject the parent table?** A cell record carries one value; the full parent grid
   gives the model the row/column context needed to verify the value and avoid misreading
   adjacent cells. Parent injection is bounded by the shared character budget.

5. **Why is the chart tier blocked?** No accepted chart descriptions exist in the index.
   Routing to a tier with no content would silently return empty evidence. The explicit
   `CHART_TIER_AVAILABLE = False` and `chart_blocked_reason` field make this state
   observable rather than silent.

6. **Is BM25/RRF A* or multi-agent reasoning?** No. Both are information-retrieval methods.
   They produce ranked lists, not proof trees, admissible heuristics or agent actions.

## Demonstration

```
# After installing the full project environment (Python 3.12, sentence-transformers, faiss-cpu):
python scripts/parse_filing.py
python scripts/prepare_evidence.py
python scripts/verify_canonical_data.py
python scripts/build_index.py

# Retrieve using the new hybrid retriever:
from src.indexing.store import ExactStore
from src.indexing.bge import BGEEncoder
from src.retrieval.dense import DenseRetriever
from src.retrieval.bm25 import BM25Retriever, HybridRRFRetriever

store = ExactStore("output/index")
encoder = BGEEncoder()
dense = DenseRetriever(store, encoder, filters={"ticker": "AAPL"})
bm25 = BM25Retriever(store.records, filters={"ticker": "AAPL"})
hybrid = HybridRRFRetriever(dense, bm25)
result = hybrid.retrieve("What were Apple total net sales in 2021?", store_parents=store.parents)
print(result["included_evidence_ids"])
print(result["stages"])
```
