## Rebuild and inspect

Use Python 3.12. Install requirements-parser.txt for the offline build, or
requirements-dev.txt for the test suite. Run:

```powershell
python scripts/prepare_evidence.py
python -m pytest -q
python -m ruff check .
```

The package preserves the 316 narrative records and three full parent grids
from the checked Apple 2021 snapshot. Its 219 child cells identify the parent,
zero-based grid row and logical column, source selector, display label, comparative
header, source units and raw displayed amount. Each tagged value records its XBRL
metric, context ID, instant or duration, dimensions, unit and power-of-ten scale.
Decimal amounts are serialized as strings. Parentheses give the displayed sign.
For example, 2021 repurchases read (85,971) in millions, or -85,971,000,000 USD.
The underlying payments concept can be positive. An EPS value of 5.61 remains
5.61 USD/share. Referenced cell/label hyperlinks and inline footnote references
are carried through when present. The working schema needs reconciliation with
the November 3 canonical contract.

## PDF and image provenance

The SEC HTML snapshot is the canonical source of searchable statement records.
The PDF is a separate 82-page rendition of the same Apple filing. Its source URL,
byte checksum, physical PDF page numbers, and image object name are pinned in
`data/source/apple-2021-renditions.json`. Docling's docling-parse backend reads
the words and bounding boxes on three checked statement pages. The method
matches a unique row label and the corresponding year column and compares the
displayed amount against its canonical cell. Eleven PDF values corroborate the
HTML records. These references retain the original PDF word coordinates and
coordinate origin. They do not add duplicate financial facts to the corpus.

The chart asset is the original embedded JPEG from physical PDF page 22. Its
SHA-256, PDF source hash and HTML image selector identify its provenance. The
saved HTML links a corresponding performance graph. The JPEG hash is for the
PDF object, not an independently downloaded SEC image. The cover graphic is
excluded. Chart captioning and question labels belong to subsequent stages.

## Coverage and limitations

`data/application_filings.json` records ten verified EDGAR filing identities
and filing-detail links, five Apple and five Microsoft 10-Ks for FY2021-2025.
Only the Apple 2021 entry has locally checked, processed source renditions.
Nine entries are inventory only. Wider ingestion and ten-company coverage
remain later corpus work. Direct requests for the SEC submissions inventories
and HTML-linked image bytes returned HTTP 403 in this environment.

This parser supports the three pinned HTML statement layouts. The PDF checks
cover specified rows in the programmatic PDF. Other pages, scans, OCR,
arbitrary layouts, complex cross-table footnote resolution and full PDF table
reconstruction are outside the verified coverage. The November 5 audit should
check grid coordinates, blanks, units and source identity independently.
